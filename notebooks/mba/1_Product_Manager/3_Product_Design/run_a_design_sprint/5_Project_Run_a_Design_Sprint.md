# Project: Run a Design Sprint

## Completing the Project

1. Review the project rubric.
2. Complete each required section of the starter template. Some sections are marked optional.
3. Remove any reference slides or text.
4. Save your completed project as a PDF.
5. Click the **Submit Project** button.

## Submission Requirements

Submit a PDF copy of your final Design Sprint project.

### Submission Options

- **Zip File:** Compress your project file or files into a single ZIP file on your computer. The upload limit is 500 MB uncompressed.
- **Project Link:** Submit a link to your completed project.
