# Project Overview

In this project, you'll have the opportunity to simulate activities that would occur during Product Development.

In the end, you will have created a test plan and a dogfood survey, and run a go / no go launch meeting, all while prioritizing the team's priorities.

## Main Steps

Here are the main steps. We'll go over each of these in more detail in the project template.

1. Create a test plan
2. Create a dogfood survey
3. Prioritize competing tasks
4. Run a Go / No Go launch meeting
