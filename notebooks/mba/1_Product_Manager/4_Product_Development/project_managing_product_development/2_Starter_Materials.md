# Starter Materials

On this page, you will be able to access and download the relevant starter materials.

1. Please make a copy of the [***Managing Product Development Project Starter Template***](<Managing Product Development Project Starter Template.pptx>). You can find all the project instructions and record all your responses in this template.
   - If you cannot access Google Slides, you can alternatively download a .pptx format of this template from the *Downloads* section in the classroom.
2. You will also need a PRD (Product Requirements Document) and a prototype to complete this project.
   - If you completed Udacity's ***Product Design*** course, you can use the PRD and prototype you created for that project as the starter for this project.
   - Otherwise, you can use the *Starter PRD* and the prototype linked in the [*Managing Product Development Project Starter Template*](<Managing Product Development Project Starter Template.pptx>). You can also download a .docx version of this document from the *Downloads* section.

## Task List

The following documents may be included in your final project:

- [ ] Create a copy of the [***Project Starter Template***](<Managing Product Development Project Starter Template.pptx>).
- [ ] Either use your own PRD and prototype from the *Product Design* course or get a copy of the provided ***Starter PRD***.

## Review the Project Rubric

Once you submit your project, we'll review your work and give you feedback if there's anything that you need to work on. Please review the project rubric to see the exact points that your reviewer will check and for some optional standout suggestions.
